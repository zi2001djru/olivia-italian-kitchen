# Oliva Italian Kitchen

A modern, responsive Italian restaurant website built with semantic HTML5, CSS3, and vanilla JavaScript.

## Live Demo

[View Live Website](https://zi2001djru.github.io/olivia-italian-kitchen/)

## About the Project

Oliva Italian Kitchen is a modern restaurant landing page designed to present an elegant dining experience through clean layouts, refined typography, and attractive food photography.

The project focuses on responsive design, visual consistency, and a user-friendly browsing experience across desktop, tablet, and mobile devices.

## Features

- Responsive design for different screen sizes
- Clean and modern restaurant layout
- Menu and food presentation
- Restaurant information and contact section
- Mobile navigation
- Elegant typography and visual styling

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Vanilla JavaScript

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.

No build tools or additional dependencies are required.
